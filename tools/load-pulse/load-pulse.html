Read this first: this runs entirely in your browser, so every request is subject to the browser's CORS policy. If your server doesn't send Access-Control-Allow-Origin headers, cross-origin requests will be blocked or reported as opaque. Enable no-cors mode in Load Test settings as a fallback — it still measures raw round-trip timing, but can't read HTTP status codes. For fully accurate results, run this from a page served on the same origin as your server, or point it at a public endpoint that allows CORS.
